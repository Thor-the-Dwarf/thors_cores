# Vorgehens-, Entwicklungs-, Prozess-, oder auch Lebenszyklus-Modelle

## Agile Modelle
### Extreme Programming (XP)
- Ablauf (User-Stories, Tests schreiben, Code entwickeln, regelmäßig ausliefern und verbessern (Refactoring)).sql
- Praktiken (Pair-Programming, Test-Driven Development (TDD), Häufige releases).sql
- Werte (Kommunikation, Einfachheit, Feedback).sql

### KANBAN
- Ablauf (visualisieren, priorisieren, kontinuierlich-bearbeiten, analysieren, anpassen).sql
- Prinzipien (Visualisierung, Abgrenzung und Optimierung - des Workflows).sql
- Werkzeuge (Kanban-Board, WIP-Limits (Work in Progress)).sql

### Scrum
- Ablauf (Backlog erstellen, Sprint planen, Daily Scrum, Sprint Review, Retrospective).sql
- Artefakte (das Increment, der Product- und Sprintbacklog).sql
- Rollen (Product Owner, Scrum Master, Entwickler).sql
- AGILES MANIFEST.sql

### Hybride Modelle
#### Entwicklungs
- Ablauf (planen, durchführen oder Prototyp entwickeln, Feedback sammeln, verbessern).sql
- Feedback (Nutzer einbindend Rückmeldungen sammeln).sql
- Planung (Anforderungen priorisierten Iterationen festlegen).sql
- Verbesserungen (Design und Code optimieren).sql

### Lean Software Development
- Ablauf (wert definieren, Prozesse analysieren MVP entwickeln, Feedback sammeln, Verbesserungen umsetzen).sql
- Methoden (Value Stream Mapping, Build-Measure-Learn).sql
- Prinzipien (Verschwendung eliminieren, Wert maximieren, schnelle Lieferung).sql

### Spiralmodell
- Ablauf (Risiken identifizieren, prototyping, bewerten, nächsten Zyklus planen, fertig stellen).sql
- Aufgaben (Prototypen, Risikoberichte, Endprodukt).sql
- Zyklen (Risikoanalyse, Prototyping, Bewertung).sql

### Klassische Modelle

### V-Modell
- Ablauf (Anforderungen Festlegen, System entwerfen, Module entwickeln, testen jeder Ebene, System abnehmen).sql
- Dokumentation (Spezifikationen, Abnahmeprotokolle, Testpläne).sql
- Testebenen (Unit-Tests, Integrationstests, Systemtests).sql

### Wasserfallmodell
- Ablauf (Anforderungen Festlegen, System entwerfen, Code implementieren, Tests durchführen, Produkt warten).sql
- Ergebnisse (Anforderungsspezifikation, Entwurfsdokumente, Testberichte).sql
- Verantwortlichkeiten (Projektleiter, Entwickler, Tester).sql
